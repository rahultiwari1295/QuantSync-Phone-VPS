# Daily Runbook

## After market close (India: 4:00 PM IST)

1. Confirm today's L0 signals were generated by the production scanner.
   ```bash
   curl -s http://localhost:8088/api/scan | head -c 200
   ```

2. Run the L5 shadow scorer:
   ```bash
   python3 deploy/l0_l5_observation/run_shadow_daily.py
   ```

3. Run the daily resolver:
   ```bash
   python3 deploy/l0_l5_observation/daily_resolver.py
   ```

4. Verify the observation page:
   ```bash
   curl -s http://localhost:8088/api/observation/status | python3 -m json.tool
   ```
